# OldMovies

**OldMovies** is a lightweight, high-speed, and responsive web-based streaming platform dedicated to preserving and showcasing the golden age of early cinema spanning the 1900s and 1910s. Built with pure HTML5, CSS3, and vanilla JavaScript, the platform curates public-domain cinematic masterpieces alongside seamless real-time search functionality and dynamic streaming fallback systems.

---

## Features

- **Curated Early Cinema Library:** Features seminal silent films, an animation, and shorts from 1902 to 1917, including works by Georges Méliès, Edwin S. Porter, and Émile Cohl.
- **Real-Time Instant Search:** Features a lightning-fast search bar powered by backend.js that filters movie cards instantly as you type based on titles, subtitles, and descriptions.
- **Hybrid Streaming Architecture:** 
  - Integrates direct, reliable Wikimedia Commons video streams for core high-demand titles to eliminate broken playback links.
  - Utilizes a dynamic metadata fetcher for Internet Archive items to automatically resolve working MP4 streams on the fly.
- **Modern Dark-Themed UI:** Features a sleek, distraction-free cinematic aesthetic designed for effortless viewing and optimal contrast.
- **Modular Codebase:** Cleanly separates layout structure (index.html), custom styling variables, and application logic (backend.js).

## Included Movies & Media Library

1. Fantasmagorie (1908) – Émile Cohl's historic animation.
2. "A Trip to the Moon" (1902) – Georges Méliès' landmark sci-fi masterpiece.
3. "The Great Train Robbery" (1903) – Edwin S. Porter's pioneering Western action film.
4. "The Perils of Pauline" - Episode 1 (1914) – The classic cliffhanger serial starring Pearl White.
5. "Regeneration" (1915) – Raoul Walsh's gritty landmark gangster drama.
6. "Intolerance" (1916) – D.W. Griffith's monumental historical epic.
7. "The Immigrant" (1917) – Charlie Chaplin's classic comedy short.
8. "The Portage Trail" (c. 1915) – A silent melodrama showcasing early 20th-century Akron, Ohio.

## Getting Started & Local Development

To run or modify this project locally on your machine:

1. Clone the repository:
   git clone https://github.com/almescorperation/oldmovies.git

2. Navigate to the project directory:
   cd oldmovies

3. Open the platform:
   Simply open index.html in any modern web browser, or launch it using a local development server extension (like Live Server in VS Code).

---

## Deployment

OldMovies is designed for effortless static hosting via GitHub Pages:
1. Push all project files (index.html, backend.js, logo.jpg) to your repository.
2. Go to your repository Settings on GitHub.
3. Navigate to the Pages section on the left sidebar.
4. Under Build and deployment, select your branch and click Save.
